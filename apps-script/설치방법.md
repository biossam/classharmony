# 클래스 하모니 · 구글 시트 연결하기 (무료, 처음 한 번)

학생들이 **각자 기기**로 설문하고, 결과를 **선생님 구글 시트**에 모으는 방법이에요.
연결하지 않아도 "이 기기로 학생 설문 받기"로 태블릿 한 대를 돌려 가며 쓸 수 있어요.

## 1. 시트와 스크립트 만들기
1. [Google 시트](https://sheets.new)에서 새 시트를 만들고 이름을 `클래스 하모니 설문`으로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 원래 있던 코드를 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을 통째로 붙여 넣고 💾 저장해요.

## 2. 선생님 코드 넣기 (중요)
학생 결과는 선생님 코드를 아는 사람만 볼 수 있어요. 이 코드는 공개 코드에 적지 않고 아래에 넣어요.

1. Apps Script 왼쪽 ⚙️ **프로젝트 설정** → 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
2. 속성 `TEACHER_KEY`, 값에 선생님만 아는 코드(예: 영어+숫자 8자 이상)를 넣고 저장해요.
3. (선택) 속성 `JOIN_CODE`에 학생 입장 코드를 넣어요. 안 넣으면 `1234`예요. 나중에 사이트에서 바꿀 수도 있어요.

## 3. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**을 골라요.
2. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 하고 **배포**를 눌러요.
3. 권한 허용 화면이 나오면 내 계정을 고르고 허용해요. ("확인되지 않은 앱"이 나오면 고급 → 이동)
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

## 4. 사이트에 연결하기
1. 클래스 하모니 교사 화면에서 **구글 시트 연결 설정**을 눌러요.
2. 웹 앱 URL과 선생님 코드를 넣고 **연결하기**를 눌러요.
3. **학생용 링크**를 복사하거나 **QR**을 띄워 학생들에게 나눠 줘요. 입장 코드는 칠판에 적어 주세요.

## 자주 묻는 것
- **학생이 다시 하면?** 같은 이름으로 다시 제출하면 새 결과로 바뀌어요.
- **새 학기·새 반은?** "새 학기·새 반으로 초기화"를 누르면 지금 결과가 시트의 `보관_날짜` 시트로 옮겨지고 새로 시작해요. 지워지지 않아요.
- **코드를 고친 뒤에는?** 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포를 눌러야 적용돼요. 주소는 그대로예요.
- **선생님 코드를 잊었으면?** 스크립트 속성에서 `TEACHER_KEY` 값을 보거나 바꾸면 돼요.
- **학생 결과는 어디에 있나요?** 선생님 구글 드라이브의 시트에만 있어요. 사이트(GitHub)에는 저장되지 않아요.
