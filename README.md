# 클래스 하모니

학생 5가지 욕구(생존·사랑/소속·힘/성취·자유·즐거움) 자가 설문과 과제 유형별 모둠 배치 도구.

- **교사용**: `index.html` (결과 표, 분포, 모둠 만들기)
- **학생용**: 교사 화면의 "학생용 링크"(`?role=student&api=…`) — 설문 화면만 열려요.
- **저장**: 구글 시트 연결(무료, [설치 방법](apps-script/설치방법.md)) 또는 이 기기에만 저장.
- **개인정보**: 학생은 실명 대신 **번호와 닉네임(선택)** 으로 설문해요. 구글 시트에는 번호·닉네임·점수만 저장돼요. 실명은 선생님이 넣는 "우리 반 명단"에만 있고, 그 명단은 선생님 기기(브라우저)에만 저장돼요.
  - 닉네임이 실명처럼 보이면(예: `김도윤`) 한 번 더 확인하고, 이 기기의 "우리 반 명단"에 있는 이름이 들어 있으면 시작하지 못하게 해요.
  - 설문 첫 화면에 "왜 하나요? / 누가 보나요?" 안내가 있어요. 욕구 설문은 심리 성향 정보라, 학부모 안내문에도 목적과 보관 기간을 밝혀 두는 것을 권해요.
  - 실명이 들어간 인쇄물(모둠표·역할 카드)은 쓰고 나면 파쇄해 주세요. 학년이 끝나면 구글 시트 결과도 "초기화"로 지워 주세요.

## 모둠 배치 방식
| 방식 | 이럴 때 | 이렇게 |
|---|---|---|
| 프로젝트·발표형 | 여러 차시 프로젝트, 조사·발표 | 다섯 욕구를 골고루, 힘/성취는 모둠당 1명 이하 |
| 창작·아이디어형 | 미술 작품, 아이디어 내기 | 자유·즐거움을 고르게, 생존 또는 힘/성취를 마무리 담당으로 1명씩 |
| 관계·협동형 | 학기 초, 친해지기, 협동 놀이 | 사랑/소속을 모둠마다 1명 이상, 힘/성취는 흩어지게 |
| 같은 성향끼리 | 욕구 단원, 자기 이해 짧은 활동 | 대표 욕구가 같은 학생끼리 |

설문은 25문항(욕구마다 5문항, 1·2순위 표시) 자기 보고라 참고 자료예요. 거의 같은 답만 고르면 다시 해 보도록 안내하고, 1순위 점수가 같으면 학생이 마지막에 하나를 골라요. 결과 화면에서 이름을 눌러 학생 자리를 바꿀 수 있어요.

## 우리 반 명단 · 이 기기 모드 잠금
- **명단 넣기**(요약 카드의 "우리 반 인원" 아래): 한 줄에 "번호 이름"(예: `7 김도윤`)으로 넣으면 선생님 화면과 인쇄물(모둠표·역할 카드)에서만 실명으로 보이고, *아직 안 한 학생*과 *명단에 없는 번호*가 보여요. 명단은 선생님 기기에만 저장되고 시트로 보내지 않아요. 다른 기기에서는 다시 넣어야 해요.
- **이 기기로 학생 설문 받기**: 처음에 선생님 비밀번호(숫자 4자리 이상)를 만들어요. 설문 중에는 비밀번호를 알아야 선생님 화면으로 돌아갈 수 있고, 새로고침해도 학생 화면에 머물러요.
