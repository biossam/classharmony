# 클래스 하모니

학생 5가지 욕구(생존·사랑/소속·힘/성취·자유·즐거움) 자가 설문과 과제 유형별 모둠 배치 도구.

- **교사용**: `index.html` (결과 표, 분포, 모둠 만들기)
- **학생용**: 교사 화면의 "학생용 링크"(`?role=student&api=…`) — 설문 화면만 열려요.
- **저장**: 구글 시트 연결(무료, [설치 방법](apps-script/설치방법.md)) 또는 이 기기에만 저장.

## 모둠 배치 방식
| 방식 | 이럴 때 | 이렇게 |
|---|---|---|
| 프로젝트·발표형 | 여러 차시 프로젝트, 조사·발표 | 다섯 욕구를 골고루, 힘/성취는 모둠당 1명 이하 |
| 창작·아이디어형 | 미술 작품, 아이디어 내기 | 자유·즐거움을 고르게, 생존 또는 힘/성취를 마무리 담당으로 1명씩 |
| 관계·협동형 | 학기 초, 친해지기, 협동 놀이 | 사랑/소속을 모둠마다 1명 이상, 힘/성취는 흩어지게 |
| 같은 성향끼리 | 욕구 단원, 자기 이해 짧은 활동 | 대표 욕구가 같은 학생끼리 |

설문은 15문항 자기 보고라 참고 자료예요. 결과 화면에서 이름을 눌러 학생 자리를 바꿀 수 있어요.
